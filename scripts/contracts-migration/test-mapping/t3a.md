## Coverage

MISSING initialize: `L2Curation.initialize` is called by `DiscoveryTest` through `abi.encodeCall` in the proxy init data (`acceptProxyAndCall`), not by a `.initialize(` call; every test runs it. `GraphCurationToken.initialize` is only callable once per clone and is called by L2Curation when it creates a pool's curation token, on the first `mint`/`mintTaxFree` of every curate test.

MISSING burnFrom: `GraphCurationToken.burnFrom` is `onlyOwner` (the owner is L2Curation) and is reached through every `curation.burn(` call. `GraphCurationToken.mint` is likewise reached only through `curation.mint` / `curation.mintTaxFree` (the grep matches `.mint(` on curation).

Additions with no old test: `test/unit/l2-curation/BondingCurve.t.sol::test_BondingCurve_TokensToSignalToTokensNoTax` calls `tokensToSignalToTokensNoTax` directly (the old suite reached it only through L2GNS).
