# T5c test mapping: RewardsManager issuance allocator and subgraph service

New tests are in `packages/issuance`, on T5a's `RewardsManagerSharedTest` (the RewardsManager Hardhat artifact behind a GraphProxy). `RMIssuanceAllocatorMock` and `RMEligibilityOracleMock` replace `MockIssuanceAllocator` / `MockRewardsEligibilityOracle`, and `RMIssuerMock` (`issuer`) plays the old `MockSubgraphService`. `curation.mint` becomes `_signal`, `helpers.mine(n)` becomes `vm.roll`, and the `hardhat_impersonateAccount` blocks become `vm.prank(address(issuer))`. The old `beforeEach` that reset the allocator to the zero address is dropped, since the fixture starts with none. Expected values are derived from the explicit rolls with the shared formula helpers and asserted exactly. No ported case uses zero-token allocations (the carried `RMIssuerMock` hook caveat does not apply; allocations are set with `setAllocation`, as the old tests did).
